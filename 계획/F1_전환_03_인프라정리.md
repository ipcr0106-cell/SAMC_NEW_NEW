## Phase 6 — `backend/main.py` (공유 파일)

### 변경 범위

`main.py`는 공유 파일이지만, 이번 수정은 **F1 전용 코드만 제거**합니다.
다른 기능의 라우터 등록, CORS 설정 등은 일체 변경하지 않습니다.

### 제거 대상

```python
# ── 제거: DB 커넥션 풀 lifespan 훅 ──────────────────────────────
@asynccontextmanager
async def lifespan(app: FastAPI):
    """앱 시작 시 DB pool 초기화, 종료 시 정리."""
    from db.connection import init_pool, close_pool
    load_dotenv(Path(__file__).parent / ".env", override=True)

    dsn = os.environ.get("F1_DATABASE_URL")
    if dsn:
        try:
            await init_pool(dsn)
            print("[lifespan] DB pool initialized")
        except Exception as exc:
            print(f"[lifespan] DB pool init failed: {exc}")
    else:
        print("[lifespan] F1_DATABASE_URL missing - F1 DB disabled")

    yield

    try:
        from db.connection import close_pool
        await close_pool()
        print("[lifespan] DB pool closed")
    except Exception:
        pass
```

### 변경 후

```python
# lifespan 제거로 아래만 남김
app = FastAPI(
    title="SAMC 수입식품 검역 AI",
    description="수입식품 검역 자동화 파이프라인 API",
    version="0.1.0",
    # lifespan=lifespan  ← 제거됨
)
```

불필요해지는 imports도 함께 제거:
```python
# 제거
import os
from contextlib import asynccontextmanager
```

> `import os`와 `asynccontextmanager`가 다른 곳에서 쓰이지 않는다면 제거.
> `from pathlib import Path`는 `load_dotenv` 호출에서 계속 쓰이므로 유지.

## 검증 체크리스트

전환 완료 후 아래 순서로 확인:

### 1. 서버 기동 확인

```bash
cd backend
python -m uvicorn main:app --reload --port 8000
```

**확인 사항:**
- `[lifespan]` 관련 로그 없음 (제거 완료)
- `F1_DATABASE_URL` 경고 없음
- 모든 라우터 정상 등록 (`/docs` 에서 F1 엔드포인트 확인)
