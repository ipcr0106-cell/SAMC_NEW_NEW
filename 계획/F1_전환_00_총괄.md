## 배경 및 목적

### 현재 문제

F1은 개발 당시 **별도 Supabase 프로젝트** (`fhnlknegbzfobnmyeceh`)를 사용했으나,
팀 공용 프로젝트는 `bnfgbwwibnljynwgkgpt`입니다.

```
현재:
  f0/F2~F5 → bnfgbwwibnljynwgkgpt (SUPABASE_URL)
  F1        → fhnlknegbzfobnmyeceh (F1_DATABASE_URL) ← 다른 프로젝트!

결과:
  F1이 f0의 pipeline_steps(step_key='0') 데이터를 찾지 못함
  → F1 현재 작동 불가
```

### 해결 방향

asyncpg 직접 연결 방식을 **supabase-py SDK로 전환**합니다.

| 항목 | 전환 전 | 전환 후 |
|------|---------|---------|
| DB 연결 | asyncpg (별도 DB URL + 비밀번호) | supabase-py (SUPABASE_URL + SERVICE_KEY) |
| 연결 방식 | asyncpg 커넥션 풀 (lifespan 초기화) | supabase 클라이언트 싱글톤 |
| 코드 스타일 | `async def` + `await db.fetch(...)` | `def` + `supabase.table(...).execute()` |
| 환경변수 | `F1_DATABASE_URL` 필요 | 불필요 (`SUPABASE_URL`/`SUPABASE_SERVICE_KEY` 공용 사용) |
| 다른 기능과의 정합성 | 불일치 (F1만 asyncpg) | 일치 (F2~F5와 동일 방식) |

## 핵심 변환 규칙

### asyncpg → supabase-py 대응표

| asyncpg | supabase-py |
|---------|-------------|
| `await db.fetchrow("SELECT ... WHERE col=$1", val)` | `supabase.table("...").select("...").eq("col", val).limit(1).execute().data[0] \| None` |
| `await db.fetch("SELECT ... WHERE col=ANY($1)", arr)` | `supabase.table("...").select("...").in_("col", arr).execute().data` |
| `await db.execute("INSERT ... ON CONFLICT DO UPDATE")` | `supabase.table("...").upsert({...}, on_conflict="col1,col2").execute()` |
| `await db.execute("UPDATE ... WHERE ...")` | `supabase.table("...").update({...}).eq("col", val).execute()` |
| `await db.execute("DELETE FROM ... WHERE ...")` | `supabase.table("...").delete().eq("col", val).execute()` |
| `await db.fetchval("SELECT COUNT(*) FROM ...")` | `supabase.table("...").select("*", count="exact").execute().count` |
| `await db.fetchrow("SELECT * FROM some_rpc($1, $2)", a, b)` | `supabase.rpc("some_rpc", {"param1": a, "param2": b}).execute().data[0] \| None` |

### 함수 시그니처 변화

```python
# 전환 전
async def some_service(db: asyncpg.Connection, ...) -> ...:
    row = await db.fetchrow("SELECT ...", val)

# 전환 후
def some_service(...) -> ...:
    supabase = get_supabase()
    result = supabase.table("...").select("...").eq("col", val).limit(1).execute()
    row = result.data[0] if result.data else None
```

### supabase-py 반환값 특성

- JSONB 컬럼: `dict`로 자동 파싱 (별도 `json.loads` 불필요)
- UUID 컬럼: `str`로 반환 (asyncpg는 `UUID` 객체)
- Timestamp 컬럼: `str` ISO 형식 반환 (asyncpg는 `datetime` 객체)
- 없는 행: `result.data` = `[]` (None이 아님)
