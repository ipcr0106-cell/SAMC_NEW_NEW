## 1. 전략과 원칙

| 원칙 | 설명 |
|---|---|
| **측정 전 변경 금지** | 모든 P0 작업 전 운영 DB 실태를 SQL로 확인 (사전 점검 §5) |
| **블록 크기 최소화** | 리스크별 독립 PR, 회귀 범위 축소 |
| **멱등성 보장** | 모든 migration `IF EXISTS`·`IF NOT EXISTS`·`ON CONFLICT DO NOTHING` |
| **팀 컨벤션 준수** | `f1_`/`f2_`/… prefix 유지, `DEFAULT` + migration, 공통 테이블 변경은 PM(성은) 사인오프 |
| **증거 수집** | 각 PR에 before/after SQL 출력 캡처 포함 |
| **롤백 전략** | 모든 migration에 `-- ROLLBACK` 블록 주석으로 명시 |

| # | 확인 항목 | SQL / 방법 | 기대값 |
|---|---|---|---|

```sql
-- Phase 4-C · 2026-04-18
-- 리스크 #1 해결: DDL을 버전관리에 포함

  id                   BIGSERIAL   PRIMARY KEY,
  category_no          INT         NOT NULL,
  category_name        TEXT        NOT NULL,
  category_definition  TEXT,
  type_name            TEXT        NOT NULL,
  definition           TEXT,
  law_source           TEXT        NOT NULL DEFAULT '식품공전 제5장',
  created_at           TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_f2_food_type_classification_category
  ON f2_food_type_classification(category_no);

CREATE INDEX IF NOT EXISTS idx_f2_food_type_classification_type_name_trgm
  ON f2_food_type_classification USING GIN (type_name gin_trgm_ops);

-- RLS
ALTER TABLE f2_food_type_classification ENABLE ROW LEVEL SECURITY;

CREATE POLICY f2_food_type_classification_select
  ON f2_food_type_classification FOR SELECT USING (true);
```
